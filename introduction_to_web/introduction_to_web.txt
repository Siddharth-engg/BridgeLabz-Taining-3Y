1. Frontend development focuses on the part of a website that users can see and interact with. It includes the design, layout, buttons, forms, and navigation of a website. Technologies such as HTML, CSS, and JavaScript are commonly used. For example, the product pages and search bar visible on Amazon are part of the frontend.

   Backend development focuses on the server-side functionality of a website. It manages business logic, user authentication, data processing, and communication with databases. For example, when a user logs into Amazon, the backend verifies the credentials and retrieves user information.

   Full-stack development combines both frontend and backend development. A full-stack developer can build the complete application, including the user interface, server-side logic, and database connectivity.

3. When a user enters a website address in a browser, the browser sends a request to the web server. The server processes the request and, if necessary, retrieves data from a database. The server then sends the required files such as HTML, CSS, and JavaScript back to the browser. The browser interprets these files and displays the webpage to the user.

4. The tools required for a web development environment are:

   * Visual Studio Code: Used as a code editor for writing and managing source code.
   * Web Browser: Used for testing and viewing websites.
   * Git: Used for version control and tracking code changes.
   * GitHub: Used for storing and managing repositories online.
   * Node.js: Provides a JavaScript runtime environment.
   * Live Server: Automatically refreshes web pages during development.

5. A web server is software or hardware that receives requests from users and delivers web content over the internet. It processes requests from browsers and sends back the required resources. Common examples include Apache HTTP Server, Nginx, Microsoft IIS, LiteSpeed, and Node.js HTTP Server.

6. A frontend developer creates and maintains the user interface of a website. A backend developer manages server-side logic, APIs, and communication with databases. A database administrator manages databases, ensures security, performs backups, and maintains data integrity.

8. A static website contains fixed content that remains the same for all users. Any changes require modification of the source code. A personal portfolio website is an example of a static website.

   A dynamic website generates content based on user interactions, databases, or server-side processing. Websites such as Amazon, Facebook, Instagram, and YouTube are examples of dynamic websites.

9. Five popular web browsers are:

   * Google Chrome
   * Mozilla Firefox
   * Microsoft Edge
   * Safari
   * Opera

   Chrome, Edge, and Opera use the Blink rendering engine. Firefox uses the Gecko rendering engine, while Safari uses the WebKit rendering engine. Rendering engines are responsible for interpreting HTML, CSS, and JavaScript and displaying web pages to users.
